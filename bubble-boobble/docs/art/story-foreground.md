# Story foreground pilots

The subsequent [all-story rollout](story-foreground-rollout.md) extends this system to all 25 levels using seven shared sets; this page preserves the approved pilot art and registration provenance.

The user approved foreground previews for Sailcloth, Acorn Antics (`garden-2`) and Boiler Brigade (`foundry-4`). The production PNGs are transparent **full-canvas 1672 × 941 overlays**, extracted with built-in ImageGen on October 29, 2026. They preserve the approved near-camera props’ original positions, proportions and painted defocus. The first 3:1 recompositions were rejected and replaced; those discarded variants are not shipped.

Each sprite is an independent texture (`atlas = "none"`) with linear filtering, ASTC6×6 compression, trimming disabled, a 1024-texel cap and a 768-texel phone-low override. No runtime blur or pixel cleanup is used.

## Registration and measured alpha

The full canvas registers its source floor at `height × (600 / 720)` = 784.1667 source pixels. Tall corner props may rise outside the playable walls; the low center remains registered below the floor.

`assets/adventure/foreground/alpha-bounds.json` is generated by reading PNG alpha without modifying pixels. It retains bounds for all nonzero pixels as diagnostics, paint bounds at alpha ≥ 4/255, and meaningful bounds at alpha ≥ 16/255. Right/bottom bounds are exclusive. Per-sprite `profileBinWidth = 32`, `paintMinRows`, and `meaningfulMinRows` give the minimum occupied source row in each horizontal bin, with `null` for an empty bin. The last bin ends at the image width. Runtime placement uses the measured alpha ≥ 4 profile inside the playable horizontal span and an eight-reference-pixel floor gap; isolated sub-4 quantization specks are not visible paint.
