# The Bubble Brigade repository

The Game Engine project is `bubble-boobble/`. Read its `PROJECT.md` first, then its `AGENTS.md`, and follow the preserved Game Engine skills. Run engine and npm commands inside that project directory; run Git at this repository root.

This repository was migrated from BubbleBoobble with its AI harness, fixtures, replay recordings, render goldens, agent configuration and historical evidence. See `bubble-boobble/docs/migration/README.md` for bootstrap, verification and source provenance. Historical `docs/git-workflow.md` refers to the source repository; use this repository's own origin for current Git operations.

Keep archived migration evidence immutable. Preserve the Game Engine-only automated gameplay testing boundary in PROJECT.md. Migration is the current scope; do not begin reskinning or develop new multiplayer features until requested separately.
